# Agro Preço

Landing page que apresenta a ideia de reunir o preço da saca em um só lugar para o produtor rural, com uma calculadora que estima o valor total de uma venda.

## Funcionalidades

- Menu fixo no topo com links para cada seção
- Seções: Apresentação, O problema, Como funciona, Experimente e Contato
- Calculadora: quantidade de sacas × preço por saca, com resultado em reais (ex.: R$ 12.450,00)
- Validação: mostra um aviso quando algum campo está vazio, zerado ou negativo
- Formulário de contato com mensagem de confirmação (nenhum dado é enviado ou armazenado)
- Layout responsivo: os cartões ficam empilhados em telas de até 600 px

## Tecnologias

HTML, CSS e JavaScript puros, sem frameworks, bibliotecas ou banco de dados.

## Como usar

Baixe ou clone o repositório e abra o arquivo `index.html` no navegador. Não é preciso instalar nada.

## Estrutura

```
index.html   estrutura da página
style.css    visual e responsividade
script.js    calculadora e formulário de contato
```
